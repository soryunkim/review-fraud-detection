# 선행연구 목록 (업데이트) — 리뷰 사기 탐지

> 작성일: 2026-08-20 · 작성자: 김소륜
> 업데이트된 계획서(신청서류 가이드 8/18 개정본) 기준으로 용어를 **구조/메타데이터 기반 / 텍스트 내용 기반 / 하이브리드(그래프)** 로 통일하고, "서베이 먼저 훑고 인용수·코드공개 기준으로 베이스라인 선정"이라는 새 전략에 맞춰 후보군을 넓혔습니다. 8/17에 만든 7원칙 상세 파일(`01~09`)과 겹치는 논문은 링크만 다시 정리했고, 이번에 새로 찾은 5편(10~14번, 특히 **신규계정형(cold-start) 전용 논문 2편**)을 추가했습니다.

## 신규계정형(Cold-start) — 사기 유형별 매핑용 신규 발견

계획서에 "데이터셋에 유형 라벨이 없으면 계정 생성일 등으로 근사 정의"한다는 항목이 추가돼서, 신규계정(cold-start) 자체를 다루는 논문을 별도로 찾아봤습니다. m×m 매트릭스의 "신규계정형" 행을 채울 후보입니다.

| # | 제목 | 저자 | 연도 | 링크 | 요약 |
|---|---|---|---|---|---|
| 13 | Unsupervised User Behavior Representation for Fraud Review Detection with Cold-Start Problem | Li, Wu, Zhu, Zhang, Zhao | 2019 | [Springer](https://link.springer.com/chapter/10.1007/978-3-030-16148-4_18) | 리뷰 텍스트 대신 행동 패턴+사회적 연결을 비지도 학습으로 표현, 이력이 부족한 신규 유저(cold-start)도 탐지. Yelp 데이터 기준 기존 방법 대비 우수. |
