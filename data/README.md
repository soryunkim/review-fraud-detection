- `raw/` — 원본 데이터 (다운로드 그대로)

## 데이터 확인 필요 사항 (미팅 기준)

- [ ] 데이터셋에 사기 유형 정보(예: 신규 계정 여부, 리뷰 버스트 여부)가 실제로 포함되어 있는지 확인
