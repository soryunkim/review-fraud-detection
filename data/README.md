## 폴더 구조

- `raw/` — 원본 데이터 (다운로드 그대로)
- `processed/` — 전처리/피처 추출 후 데이터 (`reviews.parquet`, `emb_minilm_384.npy`, `features_handcrafted.parquet` 등)
