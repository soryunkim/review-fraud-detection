# 킥오프 미팅 (2026-08-11)

참석: 김민경 교수님, 오동진, 이유진, 김세언, 김소윤 (독립심화학습 전체 킥오프 — 3개 팀 합동)

전체 미팅 정리본은 별도 문서 참고(과목 공통 가이드라인, 학회 정보, 다른 팀 주제 포함). 여기서는 **우리 팀(리뷰 사기 탐지) 관련 내용만** 정리합니다.

## 팀 정보

- 팀원: 오동진, 김민섭, 김소윤
- 주제: 가짜 리뷰(사기 리뷰) 탐지 — 사기 유형별 구조/텍스트/하이브리드 방법론 비교분석

## 배경 및 문제 인식

- 이전 공모전 경험: 저주파(low-frequency, spectral) 방식 사용 → 성능 저조. 원인: 사기 리뷰(노드) 주변에 진짜 리뷰가 많아 신호가 희석됨.
- 조사 결과: **spectral 계열 논문(약 7편 검토)은 텍스트 임베딩(의미 정보)을 전혀 사용하지 않고, 사전 가공된 32차원 행동/구조 피처만 사용**. 반대로 spatial 계열은 텍스트 임베딩을 쓰는 경우가 많음.
- 관련 근거: 2015년경 비교 연구에서 "행동 피처가 텍스트 의미 정보보다 성능에 더 중요하다"는 결과가 있었음 (단, 당시 텍스트 임베딩 기술은 BoW/TF-IDF 수준). 트랜스포머/LLM 등장 이후에도 spectral 계열은 여전히 텍스트 임베딩을 배제하는 경향 → 구조적 이유가 있을 가능성.

## 방향 전환

- 초기 아이디어(텍스트 임베딩 추가로 새 SOTA 달성)는 "2달 안에 SOTA를 새로 만드는 건 욕심"이라는 판단 하에 **기각**.
- **최종 방향(교수님과 합의)**: 리뷰 사기 유형(예: 신규 계정형, 버스트형 등)별로 구조 기반 / 텍스트(컨텍스트) 기반 / 하이브리드 방법론의 성능이 어떻게 달라지는지 **m × m 매트릭스로 비교분석**.
  - 포지셔닝: 해석가능성(interpretability) 향상을 위한 기초 연구. "어떤 방법론이 어떤 사기 유형을 간과하는지"를 밝혀 향후 결합 방향을 제시.
  - 비교 시 관점(구조 중심 / 텍스트 중심 / 하이브리드)을 명확히 할 것.
