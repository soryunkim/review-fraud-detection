# 실험 매트릭스 (조건 A/B/C × 사기 유형)

> 9/2 피드백([`meeting_notes/2026-09-02_professor_feedback.md`](meeting_notes/2026-09-02_professor_feedback.md)) 반영. 목표·배경은 [`project_plan.md`](project_plan.md), 라벨링 상세는 [`progress_reports/전처리_progress_report.md`](progress_reports/전처리_progress_report.md) 참고. 이 문서는 실행 순서·상태만 추적하는 용도.

## Phase 1 — 데이터셋 확정 및 스키마 검증

**목표**: 텍스트 포함 YelpZip을 데이터셋으로 채택하고, 리뷰-업체-작성자 관계가 그래프로 매핑 가능한지 검증한 뒤, **조건 A/B가 공유할 그래프 구성 방식을 하나로 확정**한다.

**방법**:

1. **라벨 분포 확인**: 사기/정상 라벨 비율, 전체 클래스 불균형 정도를 먼저 파악.
2. **그룹핑 가능성 검증**: reviewer_id / product_id로 실제 관계 엣지를 구성할 수 있는지 확인 — 해당 컬럼의 존재 여부, 결측치, 그룹 크기 분포(예: 작성자당 평균 리뷰 수) 점검.
3. **관계별 라벨 동질성 측정**: R-U-R(동일 작성자) / R-S-R(동일 상점) / R-T-R(동일 시점) 각각에 대해, 같은 엣지로 연결된 두 리뷰의 라벨이 실제로 상관이 있는지 측정.
4. **그래프 구성 후보 설계** (조건별로 다르게 고르는 게 아니라, A/B가 공유할 단일 후보군):
   - 후보 ①: 동질성 높은 관계만 엣지로 사용
   - 후보 ②: 동질성 낮은 관계는 엣지 대신 그 관계에서 파생된 집계 통계를 노드 피처로 흡수
   - 후보 ③: 이종 그래프(R-GCN/HAN 등)로 관계 타입별 가중치를 모델이 학습하게 함
5. **후보 비교는 조건 A만으로 수행**: 조건 A가 실행 우선순위 1번이라 가장 먼저 도니, 이걸 테스트베드 삼아 후보 ①~③ 중 어느 그래프 구성이 나은지 비교하고 하나로 확정한다. (조건 B로 후보를 나눠 비교하지 않는다 — 그러면 A/B 비교 자체가 오염됨)
6. **확정된 그래프 구성을 B에 그대로 재사용**: 그래프 구조(엣지셋·가중치·관계 처리 방식)는 A/B 간 고정. 노드 피처(수작업 vs 텍스트 임베딩)만 달라지도록 유지.
7. C는 그래프를 아예 쓰지 않는 게 설계 의도이므로 이 단계와 무관 — 그대로 진행.

**산출물**: 데이터셋 채택 근거, 관계별 라벨 동질성 결과표, 확정된 그래프 구성 방식 1건(A/B 공통 적용 대상).

> **핵심 원칙**: 그래프 구성 방식을 탐색하는 실험과, A vs B 매트릭스 비교 실험은 분리한다 — 전자는 A만으로 먼저 끝내고, 후자는 그 결과를 고정값으로 물려받는다. 매트릭스 비교의 유일한 변수는 "노드 피처 종류"여야 하므로, 그래프 구조를 조건별로 다르게 실험하면 A vs B 비교 자체가 무의미해진다.

## 조건 정의 (열)

| 조건 | 그래프 구조 | 노드 피처 | 모델 |
|---|---|---|---|
| A. 구조/메타데이터 기반 | 사용 (Phase 1에서 확정된 구성) | 수작업 표층 피처 (38차원) | 바닐라 GNN(GCN/GraphSAGE) → PC-GNN → (여유 시) BWGNN |
| B. 하이브리드 | 사용 (Phase 1에서 확정된 구성, A와 동일) | 고차원 텍스트 임베딩 + 상점 메타데이터 | GNN |
| C. 텍스트 전용 | 미사용 | 텍스트 임베딩만 | MLP (non-GNN, 순수 베이스라인) |

## 유형 정의 (행)

- **신규계정형**: 작성자 전체 리뷰 수 ≤ 임계값. 전체 데이터 기준으로 계산(표본 기준 계산 시 오탐 39.8% 확인됨).
- **버스트형**: 같은 상점 7일 내 3건 이상(전역 윈도우) + 극단평점(1/5점) + 평점이탈 > 1.5 (Fei et al. 2013 방식). 상점별 KDE 단독 정의는 사기 판별력 없음(13.9% ≈ 전체 평균)이라 폐기.
- **신규&버스트 교집합(혼합)**: 두 조건 동시 만족. 표본이 부족하면 "일반"으로 통합.

## 실행 우선순위

축소 우선순위: 유형은 **신규계정형 → 버스트형 → 신규&버스트 교집합** 순, 조건은 각 유형 안에서 **A → C → B** 순(A는 이미 검증된 순수 구조 기준선, C는 구현이 가장 간단한 대조군, B는 구현 난이도가 가장 높은 결합 조건이라 마지막). 시간이 부족하면 교집합 행(우선순위 7~9)은 생략하고 2×3(우선순위 1~6)까지만 채워도 최소 목표 달성.

## 공통 유의사항

- 셀마다 라벨 정의에 쓰인 변수(`singleton` 등)를 제외한 버전을 병행 보고해 라벨 누수를 점검한다.
- 사기율이 유형별로 크게 다르므로(3~26%) AUROC/AUPRC와 함께 베이스라인 대비 lift를 병기한다.
