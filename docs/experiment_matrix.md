## 유형 정의 (행)

- **신규계정형**: 작성자 전체 리뷰 수 ≤ 임계값. 전체 데이터 기준으로 계산(표본 기준 계산 시 오탐 39.8% 확인됨).
- **버스트형**: 같은 상점 7일 내 3건 이상(전역 윈도우) + 극단평점(1/5점) + 평점이탈 > 1.5 (Fei et al. 2013 방식). 상점별 KDE 단독 정의는 사기 판별력 없음(13.9% ≈ 전체 평균)이라 폐기.
- **신규&버스트 교집합(혼합)**: 두 조건 동시 만족. 표본이 부족하면 "일반"으로 통합.

## 실행 우선순위

축소 우선순위: 유형은 **신규계정형 → 버스트형 → 신규&버스트 교집합** 순, 조건은 각 유형 안에서 **A → C → B** 순(A는 이미 검증된 순수 구조 기준선, C는 구현이 가장 간단한 대조군, B는 구현 난이도가 가장 높은 결합 조건이라 마지막). 시간이 부족하면 교집합 행(우선순위 7~9)은 생략하고 2×3(우선순위 1~6)까지만 채워도 최소 목표 달성.

## 공통 유의사항

- 셀마다 라벨 정의에 쓰인 변수(`singleton` 등)를 제외한 버전을 병행 보고해 라벨 누수를 점검한다.
