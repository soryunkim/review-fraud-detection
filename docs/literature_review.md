# 선행연구 조사 (Literature Review)

교수님 가이드라인: 핵심 논문(Inspirational Papers, 2~5편)은 아래 7가지 요소로 정독 분석. 기타 논문은 배경 참고용으로 별도 관리.

## 핵심 논문 (Core / Inspirational Papers)

각 논문마다 아래 템플릿을 복사해서 작성하세요.

### [논문 제목] (저자, 연도)

- **분류:** structural / textual / hybrid / survey
- **인용 위치(예정):** 서론 / 방법론 / 결론
- **코드 공개 여부:** Y/N (링크: )

1. **Main Topic** — 저자가 던지는 메인 리서치 퀘스천 / 서브 퀘스천:
2. **How** — 문제 해결을 위한 주요 접근법:
3. **Data** — 데이터셋 개수 / 크기 / 수집기간 / 내용 / 공개여부 (비공개면 직접 수집 가능한지):
4. **Experimental Setups** — 실험 설계, 평가 방법:
5. **Results** — 주요 결과:
6. **Significance** — 과학적 기여 (독창성 / 성능향상(정확도·확장성·해석가능성) / 일반화 / 새 도메인 적용 등):
7. **Discussion** — 전반적 평가, 한계점, 재현 가능 여부, 한계를 극복할 아이디어/플랜:
