## 2. 그 결과, 결정된 내용

| 구분 | 확정 내용 |
|---|---|
| 비교 조건(3가지) | **A**. 구조/메타 + 수작업피처(GNN) / **B**. 하이브리드 = 구조/메타 + 고차원 텍스트임베딩 + 상점메타(GNN) / **C**. 텍스트 전용 MLP(non-GNN, 순수 베이스라인) |
| GNN 백본 | 1단계 바닐라 GNN(GCN/GraphSAGE, 필수) → 2단계 PC-GNN(필수) → 3단계 BWGNN(여유 시) |
| 사기 유형(우선순위) | ① 신규계정형(리뷰수≤3) → ② 버스트형(재정의, §3-2) → ③ 믹스형·일반(표본 충분 확인됨) |
| 데이터셋 | **YelpZip 확정**(608,458건) — YelpChi 공개 배포판은 텍스트 원문이 없고(32차원 수작업 피처만 존재), 텍스트 포함 원본은 원저자 회신 없어 채택 불가. 동일 저자가 수집한 YelpZip(텍스트 전량 포함)으로 전환 |
| 그래프 구성 | R-U-R(동일 작성자)만 라벨 판별력 있음(라벨 동질성 0.90) — R-S-R/R-T-R은 무작위 수준이라 미사용 |
| 라벨 누수 방지 | 유형 정의에 쓰인 변수(예: `singleton`)를 제외한 버전을 병행 보고 |

## 3. 지금까지 작업된 내용 (진행 상황)

### 3-1. 완료된 작업

- 8/31 프로젝트 계획안 제출, 핵심 논문 3편(CARE-GNN·Ott et al.·FraudSquad) 정독 완료
- 9/2 피드백 반영해 비교 조건·백본·서브유형·데이터셋 재정의
- **데이터셋 확정**: YelpZip(608,458건 / 260,239 유저 / 5,044 업체 — 서베이 등재치와 업체 수 일치) 채택, R-U-R/R-S-R/R-T-R 관계 매핑 스키마 검증 완료
- **사기 서브유형 라벨링**: 신규계정형(302,070건, 23.0%) / 믹스형(14,046건, 35.8%) / 버스트형(아래 참고) — 전체 사기율 13.22% 대비 1.7~2.7배
- **버스트형 라벨 재설계 완료(담당: 김민섭)** — 전역 고정 임계값(7일/5건) 임시 라벨은 버스트 구간 사기율이 오히려 전체 평균 이하(9개 조합 중 8개 실패)로 확인되어 폐기. 교수님 지시대로 **상점별 KDE(적응형) 정의를 1차로 구현**했으나 순수 시간 밀도 신호는 사기와 무관(사기율 13.9% ≈ 전체 평균)했고, 평점 조작 신호를 결합하면 사기율 31%로 오르지만 표본이 2,623건으로 급감해 GNN 학습에 부적합했음. 이에 시간축만 전역 윈도우(7일 3건)로 완화하고 평점 신호(극단평점+이탈>1.5)는 유지하는 Fei et al.(2013) 방식으로 재설계 → **19,077건, 사기율 28.11%**(임시 라벨 11.62% → 2.4배 개선)의 균형점 채택. "버스트+평점조작(coordinated burst)" 결합 정의로 최종 보고 예정 (상세: [`전처리_progress_report.md`](전처리_progress_report.md) §4)
- **수작업 피처(조건 A 입력) 38차원 생성 완료** — 이 중 13개(34%)가 텍스트 파생 표층 통계로, "구조 계열도 텍스트를 일부 쓴다"는 9/2 피드백을 데이터로 재확인. 참조 구현(FraudSquad) 피처 계산 버그 4건 발견·수정
- **텍스트 임베딩(MiniLM, 384차원) 생성 완료**, 로더 헬퍼(`src/data/loaders.py`) 및 사용 가이드 작성
- **조건 A vs C 예비 결과(선형 프로브, 그래프 미사용)** — AUROC 기준 수작업 피처가 전반적으로 우수하나 격차가 유형마다 상이(신규계정형 +0.047 vs 버스트형 +0.183) — 신규계정형에서 구조 우위가 작아진다는 가설과 일치
- **조건 A 바닐라 GNN 실제 구현 및 신규계정형 1차 결과** — R-U-R 그래프(작성자 단위) + 수작업 피처(38차원) + 바닐라 GCN. 신규계정형 부분집합(노드 164,422개, 사기율 25.7%)에서 **test AUROC 0.725 / AUPRC 0.465 / F1 0.504** 확인. 동일 작성자 리뷰 1건뿐인 고립 노드가 69%(113,488개)로, "신규계정형은 R-U-R 구조 신호가 정의상 빈약하다"는 기존 가설과 일치하는 방향
