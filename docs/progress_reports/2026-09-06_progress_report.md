| 사기 서브유형 | 신규계정형 / 버스트형 / 혼합(신규+버스트) 3종으로 재정의. 시간 부족 시 2×3로 축소 가능 — 신규계정형 우선, 버스트형 다음. |
| 데이터셋 | FraudSquad(LLM 생성 데이터) 사용 보류 — GPT 생성 텍스트가 과도하게 정교해 텍스트 중요도가 왜곡될 위험. YelpChi(텍스트 포함 원본) 원저자 회신 대기 → 이후 회신 없음이 확인되어 **YelpZip으로 확정**(아래 2절). |
| GNN 백본 | CARE-GNN(강화학습 기반)은 성능 저하 원인 분석이 어려워 제외. 바닐라 GNN(GCN/GraphSAGE) → PC-GNN(불균형 보정) → (여유 시) BWGNN(주파수 보정) 단계적 적용 권장. |
| 버스트형 정의 | 전역 고정 임계값 금지. 상점별로 개별 KDE(커널 밀도 추정)를 적합해 리뷰 시간 분포를 구하고, 분포 꼬리(상위 약 5%)를 버스트로 정의하는 적응형 방식 채택. |
| 텍스트 임베딩 | 리뷰 텍스트 임베딩 생성 시 상점(업체) 메타데이터도 함께 인코딩할 것. |
| 실험 설계 타당성 | 마지막 조건(MLP)이 GNN이 아니어도 무방 — 유형별 인사이트를 매트릭스 각 셀에서 주장하기 위한 필수 베이스라인. |

## 2. 진행 상황

### 2-1. 완료된 작업

- 8/31(월) 자정 전 프로젝트 계획안 교수님께 제출 완료
- 핵심 논문(정독 대상) 3편 분석 완료 — CARE-GNN(Dou et al., 2020), Ott et al.(2011), Liu et al.(2025, FraudSquad)
- 9/2 미팅 피드백 반영해 비교 조건·백본·서브유형·데이터셋 방향 재정의
- **데이터셋 확정: YelpZip을 주 데이터셋으로 확정** — YelpChi 공개 배포판(`YelpChi.mat`, 3곳 배포처 MD5 동일 확인)에는 리뷰 원문이 아예 없고 32차원 수작업 피처만 있음을 확인, 텍스트 포함 원본 요청에는 원저자 회신 없음. 동일 저자(Rayana & Akoglu, 2015)가 수집한 YelpZip(608,458건, 260,239 유저, 5,044 업체 — Shehnepoor 서베이 등재치와 업체 수 정확히 일치)을 원문·구조를 모두 갖춘 주 데이터셋으로 채택
- **상점-리뷰 매핑 스키마 검증 완료** — `prod_id`로 리뷰가 그룹핑되어 있어 R-U-R(동일 작성자)/R-S-R(동일 업체+평점)/R-T-R(동일 업체+월) 관계 그래프 구성 가능 확인
- **사기 서브유형 라벨 생성** — 신규계정형(작성자 총 리뷰수 기준, 계정생성일 컬럼이 없어 대체) / 버스트형(현재는 전역 고정 임계값 기반 **임시** 라벨, 7일/5건) / 혼합 / 일반 4개 층, 전체 608,458건 기준 각 층 표본수·사기율 산출 완료
- **관계 그래프 구조 분석** — R-U-R만 라벨 판별력 있음(라벨 동질성 0.90, 나머지 두 관계는 무작위 수준) 확인. 리뷰 1건만 쓴 작성자(전체의 28.0%, 사기율 29.8%)는 R-U-R 이웃이 정의상 0개라는 점에서, 신규계정형은 구조 신호가 약해 텍스트 정보의 상대적 기여가 클 것이라는 작업 가설의 근거를 확보
- **수작업 피처(조건 A 입력) 38차원 생성 완료** — 이 중 13개(34%)가 텍스트 파생 표층 통계임을 확인, "구조/메타데이터 기반도 텍스트를 일부 쓴다"는 9/2 피드백을 데이터로 재확인
- **텍스트 임베딩(MiniLM, 384차원) 생성 완료**, 로더 헬퍼(`src/data/loaders.py`) 및 사용 가이드 작성
- **조건 A vs C 예비 결과(선형 프로브, 그래프 미사용)** — AUROC 기준 수작업 피처가 전반적으로 텍스트 임베딩보다 우수하나, 격차가 유형마다 상이(신규계정형 +0.047 vs 버스트형 +0.183) — 신규계정형에서 구조·메타 정보의 우위가 작아진다는 가설과 방향이 일치
