# 리뷰 단위 그래프 기여 지표 (소륜, 2026-09-30)

스크립트: `scripts/15_review_level_gain.py` — 9/21 제출 요약 §8 질문2 선택지 ②

칸별 PR-AUC는 그 칸의 걸러진 리뷰 수로 검정력이 정해진다(`../score_by_type/README.md`
참고 — 평점 이탈형 칸은 재학습해도 여전히 판정 불가). 이 스크립트는 PR-AUC 대신 리뷰
한 건마다 Δscore = GNN 점수 − MLP 점수(seed 5개 평균)를 재고, **AUC(Δscore, 사기
라벨)**로 "그래프가 사기 리뷰를 정상보다 체계적으로 더 밀어올렸는가"를 본다. 이 지표는
칸 안의 (사기, 정상) 쌍 전체를 쓰므로 표본이 걸러진 리뷰 수(73건)가 아니라 칸 전체
크기(671건)에 가까워진다.

## 결과 (12월 test, R-U-R, GraphSAGE)

| 칸 | n(사기) | AUC(Δscore, 사기) | 95% CI |
|---|---|---|---|
| 전체 | 8,988 (633) | 0.631 | [0.602, 0.658] |
| 버스트형 | 329 (66) | **0.692** | [0.645, 0.767] |
| 버스트 아님 | 8,659 (567) | 0.622 | [0.592, 0.650] |
| 평점 이탈형 | 671 (73) | **0.616** | [0.556, 0.675] |
| 평점 이탈 아님 | 8,317 (560) | 0.630 | [0.597, 0.662] |
| 일반 | 8,013 (498) | 0.621 | [0.590, 0.655] |

CI는 상점 단위 cluster bootstrap 1,000회.

## 해석

**§6-3에서 "판정 불가"였던 두 칸 모두, 리뷰 단위로는 유의하다.** 평점 이탈형
0.616 [0.556, 0.675], 버스트형 0.692 [0.645, 0.767] — 둘 다 95% CI가 0.5(그래프가
사기·정상을 못 가름)를 완전히 벗어난다. 특히 버스트형은 전체 칸(0.631)보다도 값이
크다 — 표본이 작아 PR-AUC로는 안 보였을 뿐, 그래프가 버스트형 리뷰에서 오히려 더
강하게 작동했을 가능성을 보여준다.

**PR-AUC 결과와 배치되지 않는다.** PR-AUC 는 "이 칸 안에서 사기 리뷰의 순위가 얼마나
높은가"(절대 성능)를 재고, 이 지표는 "그래프를 더했을 때 그 순위가 방향에 맞게
움직였는가"(상대 변화, 쌍대 비교)를 잰다. 표본이 작을 때는 후자가 통계적으로 더
안정적이다 — 같은 리뷰를 두 모델로 비교하는 짝지은 설계라 개별 모델의 잡음이
상쇄되기 때문이다(`10_paired_bootstrap.py`의 짝지은 부트스트랩과 같은 원리).

**주의**: 이 지표는 PR-AUC 와 척도가 달라 §3~§6 의 dAP(PR-AUC 단위) 수치와 직접 비교할
수 없다. "판정 가능/불가"만 보완하는 용도로 쓰고, 본문 표에 대체 삽입하려면 별도 해석
문구가 필요하다.
