# 그래프 기여의 회귀 분석 (소륜, 2026-09-30)

스크립트: `scripts/16_graph_gain_regression.py` — 9/21 제출 요약 §8 질문2 선택지 ④

칸으로 나누지 않고, 비저활동형(high) 전체 test 리뷰(12월, 8,988건, R-U-R,
GraphSAGE)에서 Δscore(= GNN − MLP, `15_review_level_gain.py`와 동일 정의)를
평점 이탈 폭·버스트 강도·작성자 이력 양에 회귀했다. 예측변수는 표준화(z-score)했으므로
계수는 "그 변수가 1 표준편차 늘 때 Δscore 가 얼마나 변하는가"다.

⚠️ **범위**: high(비저활동)형만 계산했다. low(저활동)형의 MLP 점수 파일이 로컬에
없어(`--save-scores` 없이 실행된 팀원 결과, git 비대상 data/) "전체 18만 건" 회귀는
아직 못 했다 — 파일이 확보되면 `--groups low high`로 확장 가능. low형은 §3에서 이미
Δscore ≈ 0 임이 확인돼 결론에 영향은 작을 것으로 본다.

## 해석

**작성자 이력이 많을수록 그래프 기여는 오히려 줄어든다.** 단변량·다변량 모두에서
유일하게 유의한 예측변수이며, 방향이 일관되게 음(−)이다. §3의 발견("평점이 튀는
리뷰는 리뷰 자체만으로 잘 잡혀 이력이 보탤 것이 없다")과 같은 논리로 설명된다 —
작성자 리뷰가 많아질수록 MLP 가 이미 쓰는 작성자 수준 집계 피처(U_avgRD, U_PR 등)
자체가 더 안정적으로 추정되어, GNN 이웃 메시지가 더할 수 있는 한계 정보가 줄어든다.

**평점 이탈 폭은 단변량에서는 유의(+0.0045)하지만 작성자 이력과 함께 넣으면 절반
가까이 줄고 유의성을 잃는다(+0.0024, CI가 0 포함)** — 평점 이탈 폭이 작성자 이력
양과 상관돼 있어(이력이 적은 작성자가 평점을 더 튀게 쓰는 경향 등) 단변량 효과의
일부가 혼입(confound)일 가능성을 시사한다. 버스트 강도는 단변량·다변량 모두 CI가
0을 걸쳐 유의하지 않다.

**§6-3·§6-4의 "판정 불가" 문제에 대한 답으로 쓸 때 주의**: 이 회귀는 "유형이
있다/없다"가 아니라 "정도"를 예측변수로 쓰므로, 논문의 유형별 비교표 형식과는
거리가 멀다(9/21 보고서 선택지 ④의 명시된 비용). 유형 표 대신 "그래프 기여를
가장 잘 설명하는 것은 평점 이탈이나 시간 집중이 아니라 작성자 이력 양 자체"라는
단일 문장 결론으로 쓰는 편이 적합하다.
