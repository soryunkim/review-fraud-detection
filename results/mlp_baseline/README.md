# MLP 기준선 (그래프 없음) — 2026-09-11, 오동진

`scripts/08_train_mlp_baseline.py`. 05(GCN)와 **그래프만 빼고** 같은 조건이다.
그룹 마스크, stratified_split, 표준화(수정본), 은닉 64, dropout 0.3, lr 0.01, patience 20이 모두 같다.
모델은 05의 VanillaGNN에 인접행렬로 단위행렬(자기 자신만)을 넣은 것으로, 수학적으로 2층 MLP와 같다.
test 지표이며 seed 5개(42, 0, 1, 2, 3)의 평균 ± 표준편차다. 괄호 안은 PR-AUC가 기준선(사기율)의 몇 배인지다.

## 1. 피처 구성별 PR-AUC

| 피처 | 개수 | 저활동 (기준선 0.209) | 비저활동 (기준선 0.063) |
|---|---:|---|---|
| 37개 전체 | 37 | **0.363 ± 0.011** (1.74×) | **0.318 ± 0.019** (5.05×) |
| 리뷰 수준 | 16 | 0.324 ± 0.009 (1.55×) | 0.140 ± 0.006 (2.22×) |
| 작성자 수준 | 11 | 0.296 ± 0.007 (1.42×) | **0.318 ± 0.011** (5.04×) |
| 업체 수준 | 10 | 0.337 ± 0.006 (1.61×) | 0.109 ± 0.007 (1.74×) |
| 텍스트 임베딩 (조건 C) | 384 | 0.333 ± 0.008 (1.59×) | 0.157 ± 0.005 (2.49×) |

- **비저활동:** 작성자 수준 11개만으로도 37개 전체와 같은 성능이 나온다. 신호가 거의 전부 작성자 이력에서 온다.
- **저활동:** 한 그룹이 두드러지지 않는다. 업체 ≈ 텍스트 ≈ 리뷰 > 작성자 순이고, 합쳤을 때(37개)가 가장 좋다.
  작성자 피처는 첫 리뷰라서 대부분 상수거나 리뷰 피처의 복사본이다.
  그래도 1.42×가 나오는 건 평점·RD·길이 정보가 들어 있기 때문이다.

## 2. GCN(Phase 1-B, seed 42)과의 비교: PR-AUC 차이 = 그래프의 기여

차이는 GCN 값에서 MLP 37개 평균을 뺀 값이고, σ는 MLP의 seed 간 표준편차다.

| | 저활동 | 비저활동 |
|---|---|---|
| R-U-R 단독 | +0.001 ~ +0.003 (+0.1~0.3σ). 이웃 0개라 MLP와 같은 모델 | **+0.103 (+5.3σ)** |
| R-U-R + R-T-R | −0.019 ~ −0.021 | −0.051 ~ −0.062 |
| R-U-R + R-S-R | −0.010 ~ −0.018 | −0.114 ~ −0.134 |
| 전체 조합 | −0.009 ~ −0.015 | −0.125 ~ −0.137 |
| R-S-R 단독 | −0.006 ~ −0.017 | −0.152 ~ −0.184 (−8~−10σ) |
| R-T-R 단독 | −0.017 ~ −0.024 | −0.152 ~ −0.158 |
| R-S-R + R-T-R | −0.020 ~ −0.022 | −0.174 ~ −0.186 |

(각 칸은 isolated와 full의 범위다.)

- **저활동:** 어떤 조합도 MLP보다 좋지 않다. 차이는 0 ~ −0.02로 대부분 2σ 이내다.
  → 기본 GCN으로는 관계 그래프의 기여가 없다.
- **비저활동:** 그래프 없음보다 좋은 건 **R-U-R 단독 하나뿐**이고, 그 효과는 매우 크다(+0.10).
  R-S-R이나 R-T-R이 들어간 조합은 모두 그래프 없음보다 크게 나쁘다.
  → R-S-R·R-T-R은 이 설정에서 "정보를 더하는" 게 아니라, MLP가 가진 자기 피처 신호를 망가뜨린다.

## 3. 해석할 때 주의할 점

1. **GCN 쪽은 seed 1개다.** MLP의 seed 간 표준편차는 저활동 0.011, 비저활동 0.019다. 그래서 차이가 0.02 안팎이면 잡음일 수 있다.
2. **"R-S-R·R-T-R이 해롭다"는 GCN 구조의 영향과 섞여 있다.**
   GCN은 자기와 이웃을 한데 평균 낸다. 그래서 자기 피처의 비중이 1/(과거 이웃 수+1)로 줄어든다(R-S-R 평균 34개면 약 3%).
   자기 피처를 따로 두는 GraphSAGE 결과(팀원 진행 중)와 나란히 봐야 한다.
3. **비저활동은 리뷰 단위 무작위 분할이다.** 같은 작성자의 다른 리뷰가 train에 들어간다.
   그래서 작성자 수준 피처와 R-U-R의 높은 점수에 "작성자를 외운 효과"가 섞였을 수 있다(미검증).
   저활동은 작성자당 리뷰가 1건이라 해당하지 않는다.
4. **검증:** 저활동 × 37개 × seed 42를 05의 R-U-R isolated(이웃 0개)와 비교하면, 초기 가중치와 epoch 1~2의 loss가 소수점 끝까지 일치한다.
   이후 부동소수점 오차로 조기 종료 시점이 갈려 PR-AUC가 0.3665 vs 0.3701이 된다. 같은 모델이라는 뜻이다.
