## 3. 읽는 법

1. **비저활동 R-U-R(GraphSAGE) 기여는 시간 단위에서 +0.061이다.** 리뷰 무작위(+0.136)보다 작성자 단위(+0.055)에 훨씬 가깝다.
   → 리뷰 무작위 분할의 부풀림은 대부분 **미래 정보**에서 왔고, 과거 이력을 허용해도 더 얻는 건 작다.
   다만 세 분할은 test 리뷰가 달라서 이 차이를 누수 크기로 바로 읽으면 안 된다.
   누수 크기는 test를 고정한 실험(A/B*/C*, 9/12 보고서 §10.1)으로 따로 잰다.
2. **저활동은 이번에도 그래프 기여가 작다.** GraphSAGE 0 ~ +0.018, GCN −0.023 ~ +0.010이다.
   GraphSAGE + R-S-R의 +0.018은 리뷰 무작위(+0.019)와 거의 같은 값이 두 분할에서 반복됐지만, seed 1개라 확정은 아니다.
3. **GCN의 "R-S-R·R-T-R이 크게 해롭다"는 시간 단위에서도 그대로다**(비저활동 −0.12 ~ −0.16). GraphSAGE는 −0.02 안팎이다. 모델 구조 탓이라는 해석(§10)과 일치한다.
4. **"유형에 따라 그래프 기여가 다르다"는 방향은 시간 단위에서도 유지된다.**
   저활동은 최대 +0.018, 비저활동은 R-U-R로 +0.061이다.

## 4. 주의

- **표준편차가 작은 건 분할이 고정이라서다.** MLP ± 0.002~0.005는 초기화 차이만 반영하고, 12월 test 표본에서 오는 흔들림은 빠져 있다.
  그래서 σ 단위 비교는 다른 분할보다 과장된다. 절대 차이로 볼 것.
  test 흔들림까지 보려면 test 점수를 저장해 부트스트랩 신뢰구간을 내야 한다(미실행).
- **GNN은 seed 1개다.**
- **첫날 동률 리뷰(9/12 보고서 §10.2)는 이 실행에 포함돼 있다**(`--drop-sameday-ties` 미사용).
- **isolated scope는 돌리지 않았다.** 지금까지 isolated와 full의 차이는 작았다.
