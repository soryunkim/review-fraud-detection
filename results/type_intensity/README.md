# 유형 강도별 관계 기여 (오동진, 2026-09-22)

스크립트: `scripts/12_type_intensity_gain.py`

버스트형·평점이탈형을 '해당/비해당' 칸으로 나누면 12월 test filtered가 수십 건이라 판단이 안 됐다.
그래서 유형을 연속 점수(강도)로 보고, test 리뷰를 점수 순 네 구간(사분위)으로 나눠 구간마다
그래프 기여(ΔPR-AUC = GNN − MLP37, 시간 분할, seed 5개 평균)를 쟀다.
CI는 상점 단위 cluster bootstrap 1,000회(seed도 복원추출).

- 강도: `burst` = −log10(max(p_life, p_90)) (09의 교집합 정의를 연속값으로), `absdev` = |평점 − 과거 가게 평균|, `down`/`up` = 깎기/띄우기 방향만
- 점수 파일: 팀원이 돌린 셀과 같은 설정으로 `--save-scores` 재실행 (low/high rtr, high rsr). 팀원 결과와의 Δ 차이는 0.003 이내

## 결과 (비저활동형)

| 가설 | Q1 → Q4 ΔAP | Q4 − Q1 | 판정 |
|---|---|---|---|
| 몰릴수록 R-T-R 기여↑ | −0.014 / −0.005 / −0.026 / −0.019 | −0.005 [−0.054, +0.046] | 추세 없음 |
| 이탈할수록 R-S-R 기여↑ | −0.026 / +0.012 / −0.036 / +0.011 | +0.037 [−0.006, +0.086] | 방향은 맞지만 유의하지 않음 |
| 작성자 관계 × 이탈 폭 | +0.053 / +0.070 / +0.051 / +0.048 | −0.005 [−0.081, +0.066] | 평탄 |

- 작성자 관계 기여가 극단 이탈 5%에서 사라지는 결과(`results/bootstrap/normal_vs_ratingdev_rur_sage_rolling.json`, 차이 +0.058 [+0.017, +0.102])는 사분위에서는 안 보인다. Q4(이탈 폭 1.07 이상)가 5% 꼬리보다 넓어서 묽어지기 때문이고, 효과는 극단 꼬리에 한정된다는 뜻이다.
- 24개 조합 중 유의하게 나온 R-T-R × down(비저활동 +0.079, 저활동 −0.064)은 방향이 서로 반대이고 구간 패턴도 들쭉날쭉해서 다중비교에 따른 우연으로 본다.
- 한계: burst Q4 경계가 p < 0.16 수준이라, 정의상 버스트(p < 0.01)는 Q4의 일부일 뿐이다. 사분위 분석은 버스트 현상 자체가 아니라 약한 경향을 본다.
