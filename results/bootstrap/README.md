# 짝지은 부트스트랩 — 그래프 기여의 신뢰구간 (2026-09-13, 오동진)

`scripts/10_paired_bootstrap.py`. 05·08 `--save-scores`로 저장한 리뷰별 test 점수를 쓴다.

- **그래프 기여 Δ** = GraphSAGE 평균 PR-AUC − MLP(37개) 평균 PR-AUC. 둘 다 seed 5개(42, 0, 1, 2, 3)의 평균이다.
- **신뢰구간(seed + test):** test 리뷰를 복원추출해 두 모델을 같은 표본으로 함께 채점하고, seed도 복원추출한다(2,000회).
  test 표본의 흔들림과 초기값의 흔들림이 모두 들어간다.
- **설정:** 시간 단위 분할(1~9월 train / 10~11월 val / 12월 test), full scope, 수작업 피처 37개
- 점수 파일은 review_id가 들어 있어서 `data/processed/scores/`(git 비대상)에 있다. 재현하려면 05·08을 `--save-scores`로 다시 실행한다.

## 읽는 법

1. **비저활동 R-U-R의 그래프 기여는 유의하다.** 신뢰구간이 0을 한참 벗어난다(하한 +0.024).
   작성자 단위 분할의 +0.055(seed 1개)와도 비슷한 크기다.
2. **다만 크기는 +0.061이 아니라 +0.050으로 보고해야 한다.**
   지금까지 인용한 +0.061은 seed 42 하나의 값인데, seed 42가 다섯 개 중 가장 높았다(0.3509). 다섯 개 평균으로 보면 +0.050이다.
3. **저활동의 가장 큰 칸도 +0.014로 작다.** 신뢰구간 하한이 +0.001로 0에 거의 붙어 있다.
   게다가 이 칸은 저활동 7조합 중 seed 42에서 가장 컸던 칸을 **골라서** 검증한 것이다.
   7개 중 최댓값을 고른 효과(다중 비교)를 감안하면 0과 구분하기 어렵다.
   → "저활동형은 그래프 기여가 없거나 매우 작다"는 결론을 유지한다.
4. **"유형에 따라 그래프 기여가 다르다"는 신뢰구간으로도 뒷받침된다.**
   비저활동 +0.050 [+0.024, +0.076] 대 저활동 최대 +0.014 [+0.001, +0.027]로, 두 구간이 겹치지 않는다.

## 짝짓기의 효과, 그리고 작은 칸 검정력에 대한 의미

- 비저활동에서 모델 하나(GraphSAGE)의 PR-AUC 오차는 반폭 ±0.036이다. 짝지어서 본 차이의 오차는 반폭 약 ±0.026으로 줄어든다.
- 실측 ρ는 **0.83(비저활동) / 0.90(저활동)**이다. 전에 가정했던 0.9~0.95보다 조금 낮다.
- 이 값을 민섭의 검정력 추정에 대입하면, 12월 test 사기가 60~70건인 작은 칸(버스트형·평점 이탈형 칸)의 차이 오차는 **±0.08~0.13** 수준이다.
  찾으려는 차이(0.02~0.06)보다 크므로, 작은 칸은 test를 늘리는 방안((c) 또는 (c'))이 필요하다는 판단은 그대로다.
